# 西安奶蛙科技大学 · 非官方趣味页

一个纯静态的开玩笑网页，把「奶蛙」梗和西安科技大学做了一次结合。

## ⚠️ 声明

- 本站与**西安科技大学**无任何关联，**非官方页面**
- 「西安奶蛙科技大学」是网友玩梗的虚构名称，**不是真实存在的院校**
- 页面内所有内容（院系设置、招生简章、校规、荣誉等）均为**虚构创作**
- 不用于、也不得用于任何招生、报名、宣传用途
- 校徽为自行绘制的奶蛙版本，未使用学校官方标识

## 技术说明

- 单文件 `index.html`，纯 HTML + CSS + 内联 SVG
- **零图片、零外链、零依赖**，断网也能打开
- 首屏为「挖矿」动画（奶蛙挥镐 → 挖出土坑 → 校徽升起）
- 尊重系统 `prefers-reduced-motion` 设置，开启后直接显示成品

## 本地查看

双击 `index.html` 即可，或用任意静态服务器托管。
